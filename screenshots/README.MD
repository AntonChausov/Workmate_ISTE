# Скриншоты экспериментов

Скриншоты диалогов с 1С:Напарником, сделанные во время экспериментов на
конфигурации `amusementpark`: промпты, вызовы инструментов, ответы,
диффы, планы, результаты тестов, ошибки, маркеры, формы в клиенте.
Описание и оценка каждого эксперимента - в файлах `../summary/`.

Один каталог - один эксперимент в одном раунде проверки. Подкаталогов
нет.

## Имя файла: `<Раунд>_<Эксперимент>_<Прогон>_<NN>_<что-на-скриншоте>.<ext>`

Пример: `R4-v108_C3.2_п1_03_код-несуществующее-поле.png`

- **Эксперимент** - код категории с номером подзадачи: `B2.3`, `C3.2а`,
  `E6.1`, `H9.2`, `A10.3`. Без номера подзадачи (`A1`, `G7`, `Медиа`,
  `Планирование`, `Память`, `Спецификация`) - эксперимент из одной
  задачи. Уточняющие промпты в том же чате (наводки, тексты ошибок) идут
  под тем же кодом. `C3` без подзадачи в июньском раунде - подготовка
  (внесенные дефекты).
- **Прогон** - `п1`, `п2`: номер повторного прогона той же подзадачи в
  новом чате. `п2` есть в `R4-v108_C3`, `R4-v108_E6` и `R1-2606_A10` (в
  A10.3 первый прогон был прерван, его скриншотов нет).
- **NN** - порядковый номер внутри подзадачи и прогона, по ходу диалога.
- **Описание** - что видно на скриншоте: `промпт`, `вызовы-инструментов`,
  `ответ`, `план`, `дифф-…`, `ошибка-…`, `результат-тестов-…`,
  `инструкция-оператору-…`, `маркер-…`, `форма-в-клиенте` и т.п.
  `часть-1/2/3` - один длинный ответ, снятый несколькими скриншотами.

`R4-v108_Спецификация/R4-v108_Спецификация_п1_05_план-напарника.md` - план,
который Напарник составил в режиме Планирование. Сохранен как есть, без
правок.
